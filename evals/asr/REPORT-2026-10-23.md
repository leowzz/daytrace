# 中文 ASR 方案实测：2026-10-23

## 结论

优先候选是 **Qwen3-ASR-0.6B**。本次同一段录音、未注入答案或热词的测试中，只有它完整识别出用户确认的“啊, 现在是人声录制”。本机 Ryzen 9700X 的 CPU 推理约 0.99 秒；RTX 4060 Ti 的 GPU 推理约 0.21 秒，都快于 4.14 秒音频时长。常驻 GPU 服务更适合句末快速返回最终文本。

远端 Xeon CPU 上的 SenseVoice INT8、Paraformer INT8 计算速度充足，但均出现“人生入职”等错误，**不能仅因速度快就替换当前 ASR**。本次没有修改正式服务的 ASR 引擎、参数或历史转写。

这是 1 个样本上的选型证据，不是整体准确率保证；重复同一音频 5 次只是计时和稳定性检查，不等于 5 个独立测试样本。

## 硬件与方法

- 远端：Xeon E5-2680 v4，12 vCPU；隔离容器限制 8 CPU / 2 GiB，模型设 8 线程。正式音频库和数据库未挂载到评测容器；输入使用 Git 样本副本。
- 本机：Ryzen 7 9700X，32 GB RAM；CPU ONNX 测试 4 线程，Qwen CPU 测试 8 线程。
- 本机 GPU：RTX 4060 Ti 8 GB，PyTorch 2.5.1+cu121，Qwen BF16、SDPA、batch=1、max_new_tokens=128；CPU Qwen 使用 FP32。运行时桌面程序已使用部分显存，未关闭用户程序。
- 样本：`107b514e-3b27-4aed-b2ef-4d81beff6590`，原始 Opus 9,328 字节，SHA-256 见各结果文件；统一解码为 16 kHz mono / 66,240 样本，时长 4.14 秒。
- 所有模型使用整段原音，不新增 VAD 丢帧，不裁掉“啊”，不加人声录制等领域提示或热词。Qwen/SenseVoice 显式设中文；Paraformer 为中英模型。
- CER 忽略标点、空白和大小写，保留所有语气词与同音字。人工参考共 8 个字符；CER 50% 代表这个样本上 4 次字符编辑，不能解读为系统整体“准确率 50%”。
- 计时为加载完成后的首次推理 + 5 次热推理；表中为热推理中位数。不包含模型加载、文件解码、采集等待、网络上传、排队、VAD 端点检测和时间对齐。

RTF = 计算秒数 / 原音秒数，小于 1 表示推理吞吐快于实时，**不代表已经实现边说边出字或对应的端到端延迟**。流式 Paraformer 的首个非空文本出现在累计喂入 1.3 秒原音后；此处是输入偏移，不是实测首字墙钟延迟。其结果会随后续输入更新。

Qwen GPU 初始化（含库导入）约 6.97 秒，加载后的第一次推理 0.93 秒，5 次热推理 0.195–0.216 秒且文本一致。PyTorch 峰值 allocated 约 1.75 GiB、reserved 约 1.77 GiB；这不包括桌面、驱动或其他程序的显存。Qwen CPU 初始化约 6.57 秒，首次推理 1.15 秒，热推理 0.987–0.999 秒。

SenseVoice 在 Windows 和 Linux 的首字结果有“啊/哦”差异，结果均保留；相同 checkpoint 不代表不同推理平台一定逐字一致。远端测试时整机可用内存约 3 GB，本次未在远端运行 Qwen FP32（仅权重约 3.75 GB，另需运行时内存）。本机 CPU 的 Qwen 耗时不能冒充远端 Xeon 耗时。

## 接入建议与准确性验收

先按“说完一句后快速返回最终文本”设计：远端保留原音、稳定片段 ID 和 UTC 锚点，交给本机常驻 Qwen3-ASR-0.6B 处理。当前手机仍是手动上传；本次模型评测没有实现自动上传或实时接口。端到端延迟需要在接入后将采集端点等待、上传、排队和推理一起测量。

正式结果还需接入 [Qwen3-ForcedAligner-0.6B](https://github.com/QwenLM/Qwen3-ASR#forcedaligner-usage) 或经过验证的对齐器，为**模型实际生成的文本**补齐句/词相对时间，并映射回每个源片段。对齐器不能用来证明文本一定听对了；本次没有测试对齐耗时或精度。流式临时文本应单独标记，最终修订保留版本和证据引用，不能直接覆盖旧结果。

建议扩大到至少 30–60 分钟、多个真实采集会话的人工标注数据：正常语音、远处/轻声、背景噪声、极短“啊/好/不行”、人名和数字、中文混英文、跨片段句子，以及没有可懂语音的片段。样本要在配置冻结后作为留出集使用，不能为每条录音单独提示答案。

建议验收指标（尚未验收）：

- 对比旧引擎的整体 CER 和各场景 CER，同时单独检查否定词、人名、数字、关键动作词，不以平均值掩盖严重语义错误。
- 检查无语音样本是否产生幻觉，以及短回应是否漏识别；不能把无转写等同于静音。
- 分别测 4 秒、15 秒、30 秒片段和并发上传下的 P50/P95 端到端延迟；给出模型常驻后的性能，另报冷启动。
- 检查词时间是否越界、是否落在对应原音，跨片段不连续处不得按拼接时钟伪造现实时间。
- 只有识别和时间对齐都过关后才替换正式后端；任何模型都不能凭这一条样本宣称整体准确性已经得到保证。
